# 📚 The Dark Library

An interactive, cinematic 3D digital library built with **Next.js 15**, **Tailwind CSS**, **Framer Motion** and **Storyblok**.

Browse a personal collection of read books on virtual shelves. Click a spine and it flies off the shelf toward the camera, opens in 3D, and reveals your notes, ratings and metadata.
